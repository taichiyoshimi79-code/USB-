# スマホ → PC キーボード入力ドングル

iPhoneで打った文章を、USBドングル（M5Stack AtomS3U）がキーボードのふりをしてPCに打ち込みます。
PCには何もインストールしません（Windowsの設定変更だけ）。全部無料で作れます（お金がかかるのはAtomS3U本体だけ）。

```
iPhone（Bluefyでページを開く） ──Bluetooth──▶ AtomS3U ──USB（キーボードとして）──▶ Windows PC
```

| ファイル | 中身 |
|---|---|
| `firmware/firmware.ino` | ドングルに書き込むプログラム |
| `web/index.html` | iPhone側の画面（Bluefyで開く） |
| `README.md` | この手順書 |

---

## 1. ドングルに書き込む（最初の1回）

1. **Arduino IDE 2.x** をインストールします（無料）。
2. ボードを追加します。
   1. 「ファイル > 基本設定 > 追加のボードマネージャのURL」に次を貼ります。
      `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   2. 「ボードマネージャ」で **esp32（Espressif Systems）3.x** をインストールします。
3. 「ライブラリマネージャ」で **NimBLE-Arduino（2.x）** をインストールします。
4. `firmware.ino` を開き、上のほうにある **合言葉** を自分のものに変えます（19文字まで）。
   ```cpp
   #define PASSPHRASE   "change-me"
   ```
5. 「ツール」メニューを次のように設定します。
   | 項目 | 設定 |
   |---|---|
   | ボード | ESP32S3 Dev Module（一覧に「M5AtomS3U」があればそれでも可） |
   | USB Mode | **USB-OTG (TinyUSB)** |
   | USB CDC On Boot | Enabled（ログを見たい時） |
6. AtomS3UをPCに差して「書き込み」を押します。
   - 書き込めないとき：本体のボタンを押したままUSBに差すと、書き込みモードになります。うまくいかなければM5Stack公式の手順を見てください。
7. 書き込みが終わったら、一度抜いて差し直します。LEDが**暗い青**になれば待機中です。

## 2. PC側の設定

**PCには、何もインストールせず、設定の変更も要りません。** 差すだけで使えます。

使う前に、次を確認してください（設定の変更ではありません）。
- **PCのIMEが「あ（日本語入力）」になっていること。** 「A」のままだと、英数字のあとのEnterが改行になります。半角/全角キーで切り替えます。
- **Microsoft IMEを使っていること。** 漢字の入力に、Microsoft IMEの「F5＝文字コード変換」と「F10＝半角英数に変換」を使っています。GoogleやATOKなど、別のIMEでは動かない可能性があります。
- PCのキーボードが日本語配列（JIS）なら、スマホの「設定」でも日本語（JIS）にしてください。英語配列なら英語（US）にします。

## 3. iPhone側を用意する

1. App Storeで **Bluefy – Web BLE Browser**（無料）を入れます。
   - SafariとChromeはBluetoothに対応していないため、Bluefyが必要です。
2. `web/index.html` をHTTPSで公開します（GitHub Pages・無料）。
   1. GitHubで**公開（Public）リポジトリ**を作り、`index.html` をアップロードします。
   2. 「Settings > Pages」で `main` ブランチを選び、保存します。
   3. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で開けるようになります。
   - コードは誰でも見られますが、合言葉はコードに書かず、スマホで入力する仕組みなので問題ありません。
3. Bluefyでそのアドレスを開き、**ブックマーク**します。
   - ホーム画面に追加すると、Safariで開いてしまい接続できません。

**ドングルが無くても試せます**：ページの「デモモード」で、画面と操作を確認できます。

## 4. 使い方

1. PCにドングルを差し、IMEを「あ」にして、文字を入れたい場所をクリックします。
2. Bluefyでページを開き、合言葉を入れて「接続」を押します。一覧から `YOSHI-KB` を選びます。
3. 状態が「接続中」になったら、入力欄に打ちます。フリックで変換して「確定」した文字が、そのままPCに入ります。音声入力や貼り付けも使えます。
4. 入力欄で文字を消すと、PCにもBS（1文字消す）を送ります。ずれたときは「入力欄をクリア」を押します（PCには何も送りません）。「停止」で、打っている途中のものを止められます。

- ひらがなは、ローマ字として打ちます。英数字は、F10で半角にして確定します。漢字・カタカナ・全角の記号は、Unicodeの4桁のコードを打って、F5で文字にします。
- 漢字は、1文字あたり約0.4秒かかります。ひらがなと英数字は速いです。
- 絵文字など、4桁を超えるコードの文字は、PCに送れないため飛ばされます。
- 長い文で、まれに半角スペースが1個抜けることがあります。

## 5. LEDの意味

| LED | 状態 |
|---|---|
| 暗い青 | スマホの接続待ち |
| 青 | 接続中（合言葉OK） |
| 緑の点滅 | ジグラーON |

- **ジグラーは、スマホがつながっていなくても動きます。** PCに差した直後からONで、60秒おきにF15キーを押します。
- 本体ボタンを押すと、ジグラーのON／OFFが切り替わります。スマホからも切り替えや間隔の変更ができます。
- 差し直すと、またONに戻ります。差した時にOFFで始めたい場合は、`firmware.ino` の `JIG_ON_AT_BOOT` を `false` にしてください。

## 6. うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 英字が、かなになる／Enterで改行が入る | IMEが「A」になっています。半角/全角キーで「あ」にしてください |
| 漢字が、`6f22` のような文字のまま残る | PCのIMEの反応が遅れています。長い文のときに起こります。ドングルのプログラムの `codeKeyMs` と `codeF5Wait` を大きくしてください |
| 漢字が出ない | Microsoft IMEか確認してください。Google日本語入力やATOKでは、F5の動きが違います |
| 記号がずれる（`@` が `"` になる など） | 設定のキーボード配列（JIS／US）がPCと合っていません |
| 数字のあとの「。」が「．」になる | Microsoft IMEの設定（数字のあとの句読点）です。IMEの設定で変えられます |
| 接続の一覧に出ない | Bluefyで開いているか確認してください。ドングルを差し直すと、待機中に戻ります |
| 「合言葉が違います」 | `firmware.ino` の `PASSPHRASE` と同じものを入れてください（大文字・小文字も区別されます） |
| リモートデスクトップ先で崩れる | 遅れで崩れやすいです。手元のPCに打ってから、コピーしてください |

PCで `USB CDC On Boot: Enabled` にしていれば、Arduino IDEのシリアルモニタ（115200）で `[BLE]` `[打鍵]` などのログが見られます。
